# 백업 및 복구
**Storage > Veritas Backup > 콘솔 사용 가이드 > 백업 및 복구**<br>
이 문서에서는 Veritas Backup을 생성하기 위한 절차와 생성 이후 콘솔을 사용하는 방법을 설명합니다.
먼저 [프로젝트 서비스 활성화 가이드](https://docs.nhncloud.com/ko/nhncloud/ko/console-guide/#_21)를 참고하여 Veritas Backup 서비스를 활성화하세요.

NHN Cloud 콘솔에서 조직과 프로젝트를 선택한 뒤 GNB(Global Navigation Bar)의 **Storage > Veritas Backup** 메뉴로 이동하면 Agent, Backup, Restore, Report 네 가지 메뉴를 이용할 수 있습니다. Report 메뉴에서는 모든 백업 및 복구 리포트를 한 곳에서 조회하고 다운로드할 수 있습니다.


## 백업 에이전트 설치

백업 및 복구 서비스를 이용하려면 먼저 에이전트를 설치해야 합니다. 에이전트를 설치할 서버 정보를 입력한 뒤 설치를 신청하면 담당자가 확인한 뒤 설치를 진행합니다. 에이전트 신청 이력 삭제를 희망할 경우 이용중인 백업/복구 서비스가 모두 중지상태일 때만 이력 삭제가 가능합니다. 에이전트 설치 상태값은 **설치대기 → 설치 접수 → 설치 완료** 순으로 변경되며, 설치 취소 시에는 목록에 **설치 취소** 상태로 노출됩니다.
1. NHN Cloud 콘솔에서 **Storage > Veritas Backup**을 클릭하세요.
2. **에이전트** 탭에서 **에이전트 설치**를 클릭하세요.
3. **에이전트 설치** 화면에서 에이전트 설치를 위한 정보를 입력한 뒤 **신청**을 클릭하세요.

* **대상 유형**: NHN Cloud 인스턴스이면 `인스턴스`를, VM이나 인스턴스가 아닌 서버이면 `그 외`를 단일 선택하세요.
  * **인스턴스 선택 시**: 현재 프로젝트 내 에이전트가 미설치된 인스턴스만 목록에 노출됩니다.
  * **그 외 선택 시**: 서버명, 호스트네임, IP, OS 유형을 직접 입력해야 합니다. 주로 DB 백업 대상 서버 자원이 `그 외` 타입에 해당합니다.
* **서버**: 에이전트를 설치할 서버를 선택하세요.
* **호스트네임**: 최소 1글자, 최대 63글자까지 입력할 수 있으며 영어 소문자(a-z), 숫자(0-9), 하이픈(-)만 사용할 수 있습니다.
* **신청명**: 50자 이내의 이름을 입력하세요. 중복 신청명 검사가 진행됩니다.
* **연결된 IP**: 인스턴스를 선택한 경우 연결된 서버의 IP 정보가 자동으로 표시되며, 백업 대역 IP인지 확인해야 합니다.
* **IP 입력**: 에이전트 설치를 위한 IP 정보를 입력하세요.
* **OS 유형**: 대상이 인스턴스인 경우 선택한 서버의 OS 정보가 표시되며, 그 외인 경우 Linux와 Windows 중 알맞은 유형을 선택하세요.

4. 에이전트 신청 목록에서 해당 신청 정보를 클릭하세요. **신청 정보** 모달 창이 표시됩니다.
5. **에이전트 설치** 행에서 **설치파일 다운로드**를 클릭해 에이전트를 내려받은 뒤 압축을 해제하고 설치하세요. 에이전트 설치가 완료되면 설치 검증을 통해 정상적인 통신 확인 단계를 진행해주세요. 검증이 완료된 경우에만 백업 서비스 신청이 가능합니다. 

* **에이전트 설치 목록**에서는 설치 대기, 설치 접수, 작업 완료 순으로 최신 상태가 정렬되며 삭제된 에이전트는 목록에 노출되지 않습니다. 이용 중인 백업이 존재하면 에이전트를 삭제할 수 없습니다.
* **상태별 액션**
  * 설치 대기: [수정], [설치 취소] 버튼이 노출됩니다.
  * 설치 접수: 버튼이 노출되지 않으며 수정이 불가능합니다.
  * 설치 완료: [백업 신청] 버튼이 노출되며, 클릭 시 해당 서버 정보가 백업 신청 페이지에 자동으로 세팅됩니다.
* **에이전트 제거 유의사항**: 에이전트 신청 이력을 삭제해도 설치된 백업 에이전트는 자동으로 제거되지 않습니다. 필요 시 직접 프로그램을 삭제해야 합니다.


## 백업 신청

에이전트가 설치 후 검증이 완료된 서버만 백업을 신청할 수 있습니다. 신청 후 백업이 완료되면 상세 페이지에서 백업 결과를 조회할 수 있습니다. 백업 결과 리포트를 발행한 뒤 스케줄을 수정한 경우 이전 스케줄의 리포트 이력과 정보는 **스케줄 이력** 탭에서 확인할 수 있습니다. 백업 신청 이력 삭제는 백업 리포트가 존재하면 불가능하며 중지만 가능합니다.

백업 목록에서는 총 7가지 상태값(**신청요청, 요청접수, 작업중, 작업완료, 중지요청, 중지 접수, 중지완료**)을 확인할 수 있습니다. 리포트 이력이 없는 경우에만 서비스를 삭제할 수 있으며, 리포트 이력이 있는 경우에는 서비스가 **중지완료** 상태가 된 뒤에 삭제 버튼이 노출됩니다. 백업 신청 페이지는 에이전트 설치 상태가 **설치완료**인 서버가 존재할 때만 진입 가능합니다.

1. NHN Cloud 콘솔에서 **Storage > Veritas Backup**을 클릭하세요.
2. **백업** 탭에서 **백업 신청**을 클릭하세요.
3. **백업 신청** 화면에서 **신청 정보**, **스케줄**, **담당자 정보 및 요청사항**을 설정한 뒤 **신청**을 클릭하세요.
* 신청 정보
  * **서버**: 백업을 신청할 서버를 선택하세요. 에이전트 상태가 **설치완료**인 서버만 목록에 표시됩니다.
  * **신청명**: 신청한 백업 신청 건을 식별하기 위한 이름을 입력하세요.
  * **유형**: 셀프서비스에서는 파일 백업을 기준으로 제공되며, 백업할 경로를 입력 후 **추가** 버튼으로 최대 5개까지 등록할 수 있습니다. 입력한 행은 제거만 가능하며 수정은 지원하지 않습니다.
* 스케줄
  * 첫 번째 행은 풀 백업(Full Backup)만 설정할 수 있으며, 두 번째 행부터는 풀 백업 또는 증분 백업(Incremental Backup)을 선택할 수 있습니다.
  * 데이터 보관 기간은 기본 2주이며 1달을 선택할 수도 있습니다.
  * 스케줄 유형, 스케줄명, 백업 주기, 시작 시간, 작업 시간을 설정할 수 있습니다.
  * **스케줄 템플릿** 버튼을 통해 자주 사용하는 스케줄을 저장하고 불러올 수 있습니다. 한 프로젝트당 최대 100개의 템플릿을 생성할 수 있습니다.
* 담당자 정보 및 요청사항
  * **담당자**: 백업 담당자를 선택할 수 있습니다. 담당자는 신청자를 제외하고 최대 2명까지 추가할 수 있으며, 요청한 서비스를 원활하게 수행하기 위해 지정된 담당자의 연락처로 별도 연락을 진행합니다.
  * **요청사항**: 백업에 필요한 요청이 있다면 자유롭게 입력하여 요청할 수 있습니다. 
  
!!! tip "알아두기"
    * 설정한 백업 스케줄에서 백업 시작일이 신청일보다 이전일 경우 다음 주 스케줄에 따라 백업이 진행됩니다. 예를 들어 이번 주 금요일에 백업 주기를 주 단위-화요일로 설정해 신청한 경우 백업은 다음 주 화요일에 시작됩니다.
    * 동일 프로젝트에 백업 신청 이력이 있다면 스케줄 템플릿을 클릭해 기존 스케줄을 불러올 수 있습니다. 사용하지 않는 스케줄은 스케줄 템플릿 모달 창에서 삭제할 수 있으며, 스케줄 템플릿 삭제 시 해당 스케줄을 사용 중인 스케줄에는 영향을 미치지 않습니다.
    * 최초 설정한 스케줄은 백업 상세 페이지에서 원하는 스케줄로 수정할 수 있습니다.
    * 선택한 데이터 용량에 따라 비용이 추가 청구될 수 있습니다.
    * 이미 사용 중인 백업의 스케줄을 수정해야 할 경우 **수정**을 클릭해 수정할 수 있으며, 스케줄 수정 시 기존 백업 이력은 스케줄 이력 탭을 통해 기존 스케줄 정보와 리포트 이력을 확인할 수 있습니다.

* **백업 상세 및 수정**
  * [리포트] 버튼을 클릭하면 백업 리포트 상세 페이지로 이동하여 작업 결과를 확인할 수 있습니다.
  * 상태가 `신청요청`인 경우 [수정] 버튼을 통해 신청 정보 전체를 수정하는 페이지로 이동합니다.
  * 상태가 `작업완료`인 경우 [스케줄 수정] 버튼을 통해 스케줄만 수정할 수 있는 페이지로 이동합니다. 기존 신청 내역 위에 덮어쓰는 방식으로 저장되며 서버, 신청명, 유형은 수정할 수 없습니다.

## 복구 신청
Veritas Backup에서 진행한 백업 이력이 존재하는 경우에만 복구가 가능합니다. 신속하고 원활한 복구 작업을 위하여 담당자가 별도로 연락을 드릴 수 있습니다.
복구 신청 후 업무 시간은 용량에 따라 상이할 수 있으며, DB백업의 경우 업무 시간(오전 10시~오후 6시) 이후 신청 건은 익일 영업일에 진행될 수 있습니다.

복구 목록에서는 총 4가지 상태값(**신청요청, 성공, 실패, 작업중**)을 확인할 수 있습니다. 이용 중인 백업이 있어야만 복구 신청 페이지로 이동 가능합니다.

1. NHN Cloud 콘솔에서 Storage > Veritas Backup을 클릭하세요.
2. 복구 탭에서 복구 신청을 클릭하세요.
3. 소스 설정, 타깃 설정, 담당자 정보 및 요청사항을 설정한 뒤 신청을 클릭하세요.

* 소스 설정
  * **소스 서버**: 복구할 소스 서버를 선택할 수 있으며 백업 이력이 존재하고 데이터 보존 기간이 유효하며 에이전트 상태가 설치 완료인 서버만 목록에 표시됩니다.
  * **신청명**: 신청한 복구 신청 건을 식별하기 위한 이름을 입력하세요.
  * **복구 상세 설정**: 백업 신청명, 유형, 백업 일시, 용량을 기준으로 복구 대상 시점을 선택하는 팝업입니다. 만료일 기준 최신순으로 정렬되어 노출되며 단일 선택만 가능합니다.

* 타깃 설정
  * **프로젝트/타깃 서버**: 기본값은 소스 서버와 동일하며, 체크를 해제하면 동일한 프로젝트 내에서 에이전트가 설치된 다른 서버로 변경할 수 있습니다. 소스와 타깃은 반드시 동일한 프로젝트에 속해야 합니다.
  * **타깃 경로**: 기본값은 소스 경로이며 자유롭게 수정 가능합니다. 입력된 경로가 실제 타깃 서버에 존재하는지는 별도로 검증하지 않습니다. **경로 초기화** 버튼을 클릭하면 모든 경로가 최초 설정된 소스 경로와 동일하게 변경됩니다.
  * **희망 작업기간**: 복구 유형이 DB인 경우 희망하는 작업 기간을 설정하세요. 실제 서비스 기간과는 차이가 있을 수 있습니다. 

* 담당자 정보 및 요청사항
  * **담당자**: 복구 담당자를 선택할 수 있습니다. 담당자는 신청자 본인을 제외하고 최대 2명까지 추가할 수 있으며, 요청한 서비스를 원활하게 수행하기 위해 지정된 담당자의 연락처로 별도 연락을 진행합니다.
  * **요청사항**: 복구에 필요한 요청이 있다면 자유롭게 입력하여 요청할 수 있습니다. 

## 리포트

* **전체 리포트 목록**: 백업 및 복구 리포트 전반을 확인할 수 있습니다. 신청명, 유형(백업/복구), 실행일 기간(기본값: 최근 3개월), 상태값(전체/성공/실패)으로 검색 및 필터링할 수 있으며, 전체 또는 선택한 목록을 엑셀 파일(ZIP 압축)로 다운로드할 수 있습니다. 구분, 신청명, 상태, 유형, 실행일, 보관만료일, 데이터 보관 기간, 용량, 평균 속도, 파일 개수, 작업 시작/종료 일시, 소요시간 등의 항목을 제공합니다.
* **백업 리포트 상세**: 용량과 속도는 KB 단위로 전달된 데이터를 GB/TB 등으로 변환해 소수점 첫째 자리까지 표기하며 둘째 자리부터는 반올림 처리합니다. 상태는 성공 시 `성공`, 실패 시 `에러코드nnn` 형식으로 노출됩니다.
* **복구 리포트 상세**: 복구 유형은 텍스트로 `일반 복구`가 노출되며, 파일 개수는 복구된 파일 수 뒤에 `files`를 붙여 표기합니다. (예: 2 files)

## 에이전트 제거
에이전트 제거 시 이용 중인 백업이 진행되지 않거나 오류가 발생할 수 있으므로 반드시 서비스를 해제한 뒤 에이전트를 제거해야 합니다. 에이전트 신청 이력을 삭제하더라도 설치된 백업 에이전트는 자동으로 제거되지 않으므로 사용자가 직접 프로그램을 삭제해야 합니다.
